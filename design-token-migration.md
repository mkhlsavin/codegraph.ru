# Миграция токенов CodeGraph

Канонический слой — токены `--cg-*`. Старый слой нужен только для документации и печатного паспорта, пока эти страницы не переведены на `ResourceShell`.

| Старый токен | Канонический токен | Срок удаления |
| --- | --- | --- |
| `--color-primary-*` | `--cg-primary*` | после перевода документации на семантические классы |
| `--color-bg-*` | `--cg-canvas`, `--cg-surface`, `--cg-surface-subtle` | после перевода документации |
| `--color-text-*` | `--cg-text-primary`, `--cg-text-secondary` | после перевода документации |
| `--shadow-*` | `--shadow-cg-*` | после перевода печатного паспорта |
| `--color-purple` | `--cg-primary` | после удаления старых схем |

Новые компоненты и публичные страницы не добавляют зависимости от старых токенов.
