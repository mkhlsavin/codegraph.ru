Key Capabilities¶

Security¶

  • RBAC – 4 роли (admin, analyst, developer, viewer), 21 разрешение
  • DLP – обнаружение и маскирование конфиденциальных данных в запросах и ответах LLM
  • LLM Security – защита от prompt-инъекций, фильтрация контента, аудит взаимодействий
  • SIEM – интеграция через Syslog, CEF, LEEF форматы

Compliance¶

  • 152-ФЗ “О персональных данных”
  • ГОСТ Р 57580 (безопасность финансовых операций)
  • Требования ФСТЭК (защита информации)
  • PCI DSS (международный стандарт)
  • ISO 27001 (международный стандарт)
  • OWASP (безопасность приложений)

Deployment¶

  • Kubernetes с горизонтальным масштабированием
  • Docker Compose для разработки и тестирования
  • Отказоустойчивая конфигурация (3+ реплики)
  • Мониторинг: Prometheus + Grafana + Alertmanager
