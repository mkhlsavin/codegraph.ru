API Documentation

External interfaces and protocol references for CodeGraph: REST, WebSocket, dashboard streaming, ACP, MCP, and gRPC endpoints.

Publication Readiness Notice¶

CodeGraph production-publication hardening for story #933 is delivered. Production deployments must still provide explicit production secrets and run the configured validation gates; local development bypasses are not production defaults.

Current production-sensitive notes:

  • Webhook endpoints require configured platform secrets; missing secrets fail closed outside explicit local-development bypasses.
  • Provider/import routes validate URL schemes and hosts, reject unsafe local path imports by default in production, and enforce group ACLs.
  • API-key machine access fails closed when credential validation is unavailable.
  • Runtime quota coverage includes durable import-job counting plus dynamic payload guards.
  • WebSocket and MCP transports require project/job-scope authorization evidence before public production claims.

Quick Start¶

Start API Server¶

uvicorn src.api.main:app --host 0.0.0.0 --port 8000

Get Authentication Token¶

curl -X POST http://localhost:8000/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "password"}'

Use Token for Requests¶

Use the token on protected project and administration endpoints.

Authentication¶

All endpoints (except /health) require authentication:

JWT Token¶

curl -H "Authorization: Bearer <token>" \
  http://localhost:8000/api/v1/me

API Key¶

curl -H "X-API-Key: <api-key>" \
  http://localhost:8000/api/v1/me

API Endpoints¶

Authentication¶

Method Endpoint Description
POST /api/v1/auth/token Get JWT token
POST /api/v1/auth/refresh Refresh token
POST /api/v1/me/api-keys Create API key
GET /api/v1/me Get current user

Documentation¶

Method Endpoint Description

GET /api/v1/documentation/projects/{project_name}/package Get generated documentation package summary
GET /api/v1/documentation/projects/{project_name}/document Get generated documentation document

WebSocket¶

Endpoint Description
/ws/v1/chat Real-time chat
/ws/v1/jobs/{id} Job progress

MCP Server¶

CodeGraph provides an MCP server for integration with AI assistants (Claude Code, Cursor, Windsurf).

# Start MCP server
python -m src.mcp --db data/projects/postgres.duckdb

Key tools: codegraph_context_retrieval_fused_search, codegraph_context_retrieval_file_read, codegraph_security_taint_analysis_run, codegraph_quality_tech_debt_report_get, codegraph_security_hypothesis_run.

See: ACP Integration (EN), MCP Operator Guide (EN), gRPC API (EN) | Интеграция ACP (RU), Руководство оператора MCP (RU), gRPC API (RU)

Interactive Documentation¶

After starting the server:

  • Swagger UI: http://localhost:8000/api/docs
  • ReDoc: http://localhost:8000/api/redoc
