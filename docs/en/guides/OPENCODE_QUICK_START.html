CodeGraph + OpenCode Quick Start

CodeGraph + OpenCode Quick Start¶

This guide shows how to connect OpenCode to CodeGraph’s CPG (Code Property Graph) analysis tools.

Prerequisites¶

  • Python 3.11+ with CodeGraph installed (pip install -r requirements.txt)
  • A parsed CPG database (.duckdb file) for your project
  • OpenCode v1.2+ installed (npm install -g opencode-ai)

Setup (2 minutes)¶

1. Create opencode.json¶

In your project root, create opencode.json:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "codegraph": {
      "type": "local",
      "command": ["python", "-m", "src.mcp", "--transport", "stdio"],
      "environment": {
        "CODEGRAPH_PROJECT": "your_project_name"
      }
    }
  },
  "instructions": [
    ".codegraph/AGENTS.md"
  ]
}

Replace your_project_name with the name registered in CodeGraph’s config.yaml.

2. Copy AGENTS.md¶

Copy the .codegraph/AGENTS.md file from the CodeGraph repository to your project’s .codegraph/ directory. This file tells OpenCode’s AI agents how and when to use CPG tools.

3. Verify¶

Launch OpenCode in your project directory:

opencode

Type /tools to confirm CodeGraph tools are loaded. You should see tools like codegraph_project_context, codegraph_query, codegraph_find_callers, etc.

First Steps¶

Explore the project¶

Ask the AI agent:

What does this project look like from a CPG perspective?

The agent will call codegraph_project_context and show you method counts, file counts, top complexity hotspots, and security findings.

Understand a file before editing¶

Show me the CPG context for src/api/main.py

The agent calls codegraph_file_context and returns all methods with metrics, callers, dead code flags, and security findings.

Review changes before committing¶

What's the impact of my current changes?

The agent calls codegraph_diff_context to analyze which methods changed, who calls them (blast radius), and whether there are security findings in the diff.

Navigate the call graph¶

Who calls the process_request function?

What would break if I change authenticate_user?

Run security analysis¶

Check for SQL injection in the database module

Run taint analysis on handle_upload

Write custom SQL queries¶

Show me all methods with cyclomatic complexity > 20

The agent generates and runs:

SELECT full_name, cyclomatic_complexity, fan_in, fan_out
FROM nodes_method
WHERE cyclomatic_complexity > 20
ORDER BY cyclomatic_complexity DESC

Available Tools Reference¶

CodeGraph provides 65 MCP tools. The most commonly used are listed below; the full reference is in .codegraph/AGENTS.md.

Tool Purpose
codegraph_project_context Project overview: stats, tables, hotspots
codegraph_file_context File analysis: methods, metrics, callers, findings
codegraph_diff_context Change impact: blast radius, security delta
codegraph_query Custom SQL on CPG database
codegraph_find_callers Call graph: who calls a method
codegraph_find_callees Call graph: what a method calls
codegraph_impact Change impact analysis
codegraph_taint_analysis Data flow: source-to-sink tracing
codegraph_search Hybrid semantic + structural search
codegraph_explain Deep method analysis
codegraph_hotspots Complexity/PageRank/centrality hotspots
codegraph_pattern_search 190+ structural pattern rules
codegraph_hypothesis Security hypothesis testing (58 CWE, 27 CAPEC)
codegraph_project_list List registered projects
codegraph_project_switch Switch active project

Troubleshooting¶

Tools not showing up¶

  • Check that python -m src.mcp --transport stdio works from your project root
  • Verify the Python environment has CodeGraph dependencies installed
  • Check opencode.json syntax (valid JSON, correct command path)

“No database connection” errors¶

  • Ensure a CPG database exists. Parse your project first: bash cd gocpg && ./gocpg parse --input=/path/to/source --output=cpg.duckdb --lang=python
  • Set the correct project in config.yaml or via CODEGRAPH_PROJECT env var

Slow responses¶

  • Large CPG databases (>100K methods) may take a few seconds for complex queries
  • Use LIMIT in custom SQL queries
  • The codegraph_file_context tool is scoped to a single file and is fast
