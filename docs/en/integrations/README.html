LLM Providers¶

Provider Config key Status
Yandex AI Studio llm.provider: yandex Production
GigaChat (Sber) llm.provider: gigachat Production
OpenAI llm.provider: openai Production
Local (Ollama) llm.provider: local Beta

Configuration in config.yaml:

llm:
  provider: yandex  # yandex, gigachat, openai, local

  yandex:
    api_key: ${YANDEX_API_KEY}
    folder_id: ${YANDEX_FOLDER_ID}

  gigachat:
    auth_key: ${GIGACHAT_AUTH_KEY}

  openai:
    api_key: ${OPENAI_API_KEY}

  local:
    base_url: http://localhost:11434

Environment Variables¶

Variable Description Required For

OPENAI_API_KEY OpenAI API key OpenAI
VAULT_TOKEN HashiCorp Vault token Vault
