Documentation / Integrations

Integrations

DocumentationLast updated: 2026-08-28
  • GigaChat integration Use GigaChat as the configured CodeGraph LLM provider when the customer's data-handling policy allows prompts to leave the CodeGraph boundary for Sber.
  • Yandex AI Studio integration Use this provider when CodeGraph may send LLM and embedding inputs to the customer's approved Yandex Cloud folder.
  • GitHub integration Use this guide when CodeGraph must import GitHub repositories, keep their CPG state aligned with pushes, and create review snapshots for pull requests.
  • GitLab integration Use this guide for GitLab.com or a self-managed GitLab instance. CodeGraph can resolve repository metadata, import a group, synchronize pushes, and create.
  • SourceCraft integration Use SourceCraft with CodeGraph when repository coordinates are known and webhook-driven CPG and merge-request review processing is required.
  • GitVerse integration GitVerse has the broadest provider-specific CodeGraph surface: repository onboarding, webhook reconciliation, manual synchronization, workflow dispatch.
  • OpenCode plugin opencode-codegraph is the maintained OpenCode adapter for CodeGraph. It adds graph-backed prompt context, guided CodeGraph commands, explicit.
  • Claude Code and Git hooks This page documents the .claude/hooks pack in the CodeGraph source checkout. It enriches Claude Code sessions with CPG context around prompts, edits.
  • External context synchronizer This advanced operator tool correlates Git history, GitHub/GitLab/Jira issues, and Sentry events with methods found in an existing CPG.
  • Remote MCP authentication Install the portable CodeGraph Agent Plugin and authorize Codex, VS Code, Cursor, GitHub Copilot, or OpenCode.
