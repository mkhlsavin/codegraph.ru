Prerequisites¶

  • Python 3.11+
  • PostgreSQL 15+ (running and accessible)
  • 16GB RAM minimum
  • 50GB free disk space

Quick Start¶

Step 1: Clone and Install¶

# Clone repository
git clone <repository-url>
cd codegraph

# Create virtual environment (conda)
conda create -n codegraph python=3.11 && conda activate codegraph

# Install dependencies
pip install -r requirements.txt

Step 2: Configure Database¶

# Set PostgreSQL password
export DATABASE_URL="postgresql+asyncpg://postgres:your_password@localhost:5432/codegraph"

# Windows PowerShell:
$env:DATABASE_URL="postgresql+asyncpg://postgres:your_password@localhost:5432/codegraph"

Step 3: Initialize Database¶

# Create database and tables
python -m src.api.cli init-db

# Create admin user
python -m src.api.cli create-admin --username admin --password admin123

Step 4: Start API Server¶

# Start server
python -m src.api.cli run --host 127.0.0.1 --port 8000

Step 5: Verify Installation¶

Open browser: http://127.0.0.1:8000/api/docs

Or use curl:

# Health check
curl http://127.0.0.1:8000/api/v1/health

# Get authentication token
curl -X POST http://127.0.0.1:8000/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

Common Use Cases¶

Access API Documentation¶

# Swagger UI
http://127.0.0.1:8000/api/docs

# ReDoc
http://127.0.0.1:8000/api/redoc

Create API Key¶

TOKEN="your_access_token"

curl -X POST http://127.0.0.1:8000/api/v1/auth/api-keys \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Application",
    "expires_days": 365,
    "scopes": ["scenarios:read", "query:execute"]
  }'

API Endpoints Overview¶

Category Endpoint Description
Auth POST /api/v1/auth/token Get JWT token
Auth POST /api/v1/auth/api-keys Create API key
Chat POST /api/v1/chat Send chat message
Scenarios GET /api/v1/scenarios List scenarios
Scenarios POST /api/v1/scenarios/{id}/query Execute scenario
Query POST /api/v1/query/execute Execute query
Health GET /api/v1/health Health check

Troubleshooting¶

Database Connection Failed¶

# Check DATABASE_URL
export DATABASE_URL="postgresql+asyncpg://postgres:correct_password@localhost:5432/codegraph"

# Reinitialize database
python -m src.api.cli init-db

Port Already in Use¶

# Kill process on port
lsof -ti:8000 | xargs kill -9

# Or use different port
python -m src.api.cli run --port 8001

PostgreSQL Not Running¶

# Linux
sudo systemctl start postgresql

# Windows
Get-Service postgresql* | Start-Service
