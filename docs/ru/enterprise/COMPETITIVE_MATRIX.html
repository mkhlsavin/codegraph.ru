Резюме¶

CodeGraph — единственное решение, сочетающее:

  • CPG-based анализ (AST + CFG + PDG + DDG + Call Graph) с верификацией уязвимостей через анализ заражения данных
  • AI-ассистент с NL-запросами к коду на русском и английском языках
  • Интегрированную DLP-защиту при работе с LLM (25+ паттернов)
  • SIEM-интеграцию в трёх форматах (Syslog, CEF, LEEF)
  • Российские LLM (GigaChat, Yandex AI Studio) для соответствия 152-ФЗ
  • Многокритериальную валидацию гипотез для снижения ложных срабатываний

Проблема рынка¶

Традиционные SAST-инструменты генерируют до 91% ложных срабатываний (Ghost Security, 2025). AI-кодогенераторы (Copilot, Cursor) создают уязвимый код в 45% случаев (Veracode, 2025). Ни одно существующее решение не объединяет глубокий CPG-анализ, AI-ассистент и стек корпоративной безопасности в одном продукте.

Уникальные преимущества CodeGraph¶

2. С проверкой заражения уязвимости¶

CodeGraph:
Source ──[data flow через N файлов]──► Sink = ПОДТВЕРЖДЁННАЯ уязвимость

Традиционный SAST:
Pattern match = ВОЗМОЖНАЯ уязвимость (до 91% ложных срабатываний)

Результат: - 100% обнаружение CVE на тестовом наборе (3/3 целевых CVE) - Снижение false positives на 60%+ по сравнению с сопоставлением шаблонов - Приоритизация по реальному риску, а не статическому severity

3. Интегрированная DLP-защита¶

                    CodeGraph                    Конкуренты
                    ─────────                    ──────────

                    │                                │
                    ▼                                ▼
              Block/Mask/Log                   Без защиты
  • 25+ паттернов: секреты, ПДн, учётные данные, API-ключи
  • Предотвращение утечки конфиденциальных данных через LLM-промпты
  • Маскирование ПДн в ответах LLM

Заключение¶

CodeGraph — единственное решение на рынке, объединяющее:

  1. CPG-based анализ с проверкой заражения уязвимостями и <20% ложных срабатываний
  2. AI-ассистент с NL-запросами к коду на русском и английском языках
  3. Интегрированную DLP для защиты LLM-взаимодействий (25+ паттернов)
  4. SIEM интеграцию в трёх корпоративных форматах (Syslog/CEF/LEEF)
  5. HashiCorp Vault для централизованного управления секретами
  6. Российские LLM (GigaChat + Yandex AI Studio) для соответствия 152-ФЗ
  7. 11 языков включая 1C:Предприятие и кросс-языковой анализ (CGO, ctypes, JNI)
  8. Agent Client Protocol (ACP) для нативной интеграции с IDE

Ни один конкурент не предлагает все эти возможности в едином решении.
