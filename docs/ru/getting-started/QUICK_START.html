Начало работы

Начало работы¶

Запустите CodeGraph за 10 минут с помощью этого краткого руководства.

Документы¶

Документ Описание
Установка Детальная установка с PostgreSQL, LLM, GoCPG
Конфигурация Аутентификация, ограничение частоты запросов, CORS, LLM

Быстрый старт¶

Предварительные требования¶

  • Python 3.11+
  • PostgreSQL 15+ (запущен и доступен)
  • Минимум 16GB RAM
  • 50GB свободного места на диске

Шаг 1: Клонирование и установка¶

git clone <repository-url>
cd codegraph

conda create -n codegraph python=3.11 && conda activate codegraph
pip install -r requirements.txt

Шаг 2: Настройка базы данных¶

export DATABASE_URL="postgresql+asyncpg://postgres:your_password@localhost:5432/codegraph"

Шаг 3: Инициализация базы данных¶

python -m src.api.cli init-db
python -m src.api.cli create-admin --username admin --password admin123

Шаг 4: Запуск API-сервера¶

uvicorn src.api.main:app --host 0.0.0.0 --port 8000

Шаг 5: Проверка установки¶

Откройте браузер: http://127.0.0.1:8000/api/docs
