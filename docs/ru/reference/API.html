Справка по API

Эта страница является актуальной точкой входа в поддерживаемые интеграционные поверхности CodeGraph.

Поддерживаемые поверхности¶

Поверхность Для чего используется
REST API HTTP-эндпоинты, аутентификация, проектный scope и сервисные сценарии.
MCP Operator Guide Интеграция агентов и инструментов через governed MCP server.
gRPC API Runtime-транспорт GoCPG, который используют сервисы CodeGraph.
WebSocket API Streaming-взаимодействие с dashboard и runtime.
ACP Integration IDE-интеграция через Agent Client Protocol.

Текущая граница¶

CodeGraph больше не документирует выполнение сырого DuckDB SQL как поддерживаемый внешний пользовательский API. Доступ к runtime-данным проекта должен идти через REST, MCP или GoCPG gRPC transport. Python-код внутри API-слоя должен использовать явный ProjectContext / ProjectScopedServices, а не global active-project fallback.

Исторические Python SDK и SQL-примеры сохранены только в docs/reference/archive/ для трассировки.
