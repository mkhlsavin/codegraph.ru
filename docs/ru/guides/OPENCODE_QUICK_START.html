CodeGraph + OpenCode: быстрый старт

CodeGraph + OpenCode: быстрый старт¶

Это руководство показывает, как подключить OpenCode к инструментам анализа CPG (Code Property Graph) CodeGraph.

Предварительные требования¶

  • Python 3.11+ с установленным CodeGraph (pip install -r requirements.txt)
  • Разобранная база данных CPG (файл .duckdb) для вашего проекта
  • OpenCode v1.2+, установленный через bun install -g opencode или npm

Настройка (2 минуты)¶

1. Создание opencode.json¶

В корне вашего проекта создайте файл opencode.json:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "codegraph": {
      "type": "local",
      "command": ["python", "-m", "src.mcp", "--transport", "stdio"],
      "environment": {
        "CODEGRAPH_PROJECT": "your_project_name"
      }
    }
  },
  "instructions": [
    ".codegraph/AGENTS.md"
  ]
}

Замените your_project_name на имя проекта, зарегистрированное в config.yaml CodeGraph.

2. Копирование AGENTS.md¶

Скопируйте файл .codegraph/AGENTS.md из репозитория CodeGraph в каталог .codegraph/ вашего проекта. Этот файл объясняет ИИ-агентам OpenCode, как и когда использовать инструменты CPG.

3. Проверка¶

Запустите OpenCode в каталоге вашего проекта:

opencode

Введите /tools, чтобы убедиться, что инструменты CodeGraph загружены. Вы должны увидеть такие инструменты, как codegraph_project_context, codegraph_query, codegraph_find_callers и другие.

Первые шаги¶

Обзор проекта¶

Задайте вопрос ИИ-агенту:

What does this project look like from a CPG perspective?

Агент вызовет codegraph_project_context и покажет количество методов, файлов, самые сложные участки кода и результаты анализа безопасности.

Изучение файла перед редактированием¶

Show me the CPG context for src/api/main.py

Агент вызовет codegraph_file_context и вернёт все методы с метриками, вызывающими функциями, флагами мёртвого кода и результатами анализа безопасности.

Проверка изменений перед коммитом¶

What's the impact of my current changes?

Агент вызовет codegraph_diff_context для анализа изменённых методов, их зависимостей (радиус воздействия) и наличия проблем безопасности в изменениях.

Навигация по графу вызовов¶

Who calls the process_request function?

What would break if I change authenticate_user?

Анализ безопасности¶

Check for SQL injection in the database module

Run taint analysis on handle_upload

Произвольные SQL-запросы¶

Show me all methods with cyclomatic complexity > 20

Агент сгенерирует и выполнит:

SELECT full_name, cyclomatic_complexity, fan_in, fan_out
FROM nodes_method
WHERE cyclomatic_complexity > 20
ORDER BY cyclomatic_complexity DESC

Справочник доступных инструментов¶

Инструмент Назначение
codegraph_project_context Обзор проекта: статистика, таблицы, проблемные участки
codegraph_file_context Анализ файла: методы, метрики, вызывающие функции, находки
codegraph_diff_context Влияние изменений: радиус воздействия, дельта безопасности
codegraph_query Произвольный SQL-запрос к базе данных CPG
codegraph_find_callers Граф вызовов: кто вызывает метод
codegraph_find_callees Граф вызовов: что вызывает метод
codegraph_impact Анализ влияния изменений
codegraph_taint_analysis Поток данных: отслеживание от источника к приёмнику
codegraph_search Гибридный семантический + структурный поиск
codegraph_explain Глубокий анализ метода
codegraph_hotspots Точки сложности: цикломатическая сложность, PageRank, центральность
codegraph_pattern_scan 190+ структурных правил поиска шаблонов
codegraph_project_list Список зарегистрированных проектов
codegraph_project_switch Переключение активного проекта

Устранение неполадок¶

Инструменты не отображаются¶

  • Убедитесь, что команда python -m src.mcp --transport stdio работает из корня вашего проекта
  • Проверьте, что в окружении Python установлены зависимости CodeGraph
  • Проверьте синтаксис opencode.json (корректный JSON, правильный путь к команде)

Ошибка «No database connection»¶

  • Убедитесь, что база данных CPG существует. Сначала разберите ваш проект: bash cd gocpg && ./gocpg parse --input=/path/to/source --output=cpg.duckdb --lang=python
  • Укажите правильный проект в config.yaml или через переменную окружения CODEGRAPH_PROJECT

Медленные ответы¶

  • Большие базы данных CPG (более 100 000 методов) могут требовать несколько секунд для сложных запросов
  • Используйте LIMIT в произвольных SQL-запросах
  • Инструмент codegraph_file_context ограничен одним файлом и работает быстро
