Подробные сценарии

Открывайте эту папку, если задача уже понятна и теперь нужны примеры работы.

Если файл SCENARIOS.md помогает выбрать направление, то эта папка помогает пройти сценарий до результата.

Как пользоваться этими руководствами¶

  1. Выберите сценарий под задачу.
  2. Возьмите готовые примеры запросов.
  3. Старайтесь держать одну и ту же сессию до завершения работы.
  4. Переиспользуйте результат в ревью, тестировании и следующих шагах.

Один важный практический совет¶

Не думайте об этих сценариях как о разрозненных приёмах. В текущей архитектуре одна и та же сессия может пройти через:

  • изучение проекта;
  • реализацию;
  • ревью;
  • тестирование;
  • сохранение полезной памяти проекта.

Именно это и даёт системе основную силу.
