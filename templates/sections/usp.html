Почему команды выбирают CodeGraph

Ключевые отличия, которые заметны в пилоте и в ежедневной эксплуатации

Технологическая основа

Инкрементальный CPG-парсер

Граф обновляется за секунды после изменений в коде

  • 11 языков в одном графе
  • Межъязыковой анализ (FFI: CGO, ctypes)
  • Режим наблюдения с уведомлениями через вебхуки
  • Git-хуки для автоматического обновления
Автоматизация изменений

Автоматический рефакторинг (AST)

190 правил для безопасной автоматизации изменений в коде

  • LLM помогает сформировать правило из описания на естественном языке
  • Предпросмотр и откат изменений
  • Механизм подтверждения операций
  • Интеграция с CI/CD конвейером
Интеграция в среду разработки

Интеграция с IDE (ACP)

Подключение к редакторам, агентам и внутренним платформам

  • Agent Client Protocol (ACP) — Zed, JetBrains, VS Code
  • MCP-сервер: stdio + HTTP/SSE транспорты
  • gRPC API для GoCPG (mTLS, API-ключи, Prometheus)
  • Потоковая передача ответов

Сравнение подходов

GitHub Copilot: помогает писать код, но не даёт корпоративный контур анализа Sourcegraph Cody: удобен для поиска, но не закрывает требования локального контура и DLP SonarQube: полезен для базовых проверок, но не верифицирует потоки данных CodeScene: фокусируется на метриках разработки, а не на безопасности кода
